# Contributing to Bracify

Thank you for your interest in Bracify!

## Contribution Policy

Bracify is developed and maintained by a single maintainer (solo development policy).

- **Pull Requests: NOT accepted.** Pull Requests from third parties are not accepted and will be closed without review. This keeps the design and direction of the project consistent.
- **Issues: welcome.** Bug reports, feature requests, and questions are all appreciated. Feedback through Issues is the best way to contribute.

## How to Open an Issue

Please search existing Issues first to avoid duplicates, then open a new one at <https://github.com/tri-comma/Bracify/issues>.

### Bug Report

- **Title**: A short, specific summary of the problem.
- **Environment**: Bracify version, Node.js version, OS, browser (and version), and the mode in use (SSR / CSR / Local Development Mode).
- **Steps to reproduce**: A minimal HTML / data example and the exact steps that trigger the problem.
- **Expected behavior**: What you expected to happen.
- **Actual behavior**: What actually happened, including error messages, console logs, or screenshots.

### Feature Request

- **Title**: A short summary of the feature.
- **Motivation**: What problem you are trying to solve.
- **Use case**: A concrete scenario where the feature would be used.
- **Proposed API**: A sketch of the attribute, syntax, or option you have in mind (with a short example, if possible).
- **Concept fit**: Go through the checklist in [docs/en/concept.md](./docs/en/concept.md#checklist-for-proposing-a-feature). Bracify features must be usable by end users with HTML and the Studio screens only.

### Question

Describe what you are trying to do, what you have tried, and where you are stuck. Include relevant code and environment details.

## 日本語 (Japanese)

本プロジェクトは作者1名で開発を行う方針のため、**第三者からの Pull Request は受け付けておりません**（確認なしでクローズされる場合があります）。

一方で、**Issue（バグ報告・機能要望・質問）は歓迎します**。Issue には次の情報を記載してください。

- バグ報告: タイトル、実行環境（Bracify / Node.js / OS / ブラウザ、動作モード）、再現手順、期待される動作、実際の動作
- 機能要望: タイトル、動機、ユースケース、提案する API（属性・構文）、コンセプトへの適合（[docs/ja/concept.md](./docs/ja/concept.md#機能を提案するときの確認項目) の確認項目）
